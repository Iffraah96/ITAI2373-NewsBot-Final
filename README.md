# NewsBot 2.0 – Intelligent News Analysis System

## Overview
NewsBot 2.0 is an NLP-based system that analyzes news articles and provides:
- Sentiment analysis
- Entity extraction
- Summarization
- Multilingual support
- Conversational interface

## Features
- Automated news processing
- Insight generation
- Batch analysis
- Robust error handling

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Open notebook:
   notebooks/07_System_Integration.ipynb

3. Run all cells

## Project Structure
- src/ → core code
- notebooks/ → experiments
- data/ → datasets
- docs/ → documentation
